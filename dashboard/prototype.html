What the results do not show

Read with care

  • Memory did not improve final accuracy; the interval includes zero.
  • The no-LLM zoo was added after seeing the agent results, so it is a post-hoc control.
  • P-values are uncorrected and descriptive.

Scope

  • Eight small datasets and three seeds; the seed also changes the split.
  • One quantized 7B model.
  • AutoGluon ran medium quality, tree models only.
  • Structured versus free-text memory and shuffled memory were not run.
